Leaflet.markercluster demos

Leaflet.markercluster provides animated marker clustering for Leaflet. These demos run on Leaflet 2.0, loaded as ES modules, unless noted otherwise.

Real-world data

  • 388 markers with the default options
  • 10,000 markers with chunked loading
  • 50,000 markers with chunked loading and a progress bar
  • disableClusteringAtZoom
  • zoomToShowLayer

Options and API

  • Custom cluster icons and convex hulls on hover
  • Spiderfy on click
  • singleMarkerMode and zoomToBounds on click
  • Adding, removing and moving markers with animation
  • clusterPane
  • GeoJSON and mixed layers

Other setups

  • Leaflet 1.9, as an ES module
  • Global script with Leaflet 1.9, no modules
